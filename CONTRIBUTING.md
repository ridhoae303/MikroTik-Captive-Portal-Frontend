# Contributing to this Project

Thank you for your interest!

Before you start, please understand:

1. **This is not Mikhmon.** This is a frontend-focused project. If you want to build a full management system, this might not be the right place.

2. **We focus on UI/UX, performance, and clean code.** If your contribution makes the portal slower or uglier, it will be rejected.

3. **Be respectful.** This is a learning and contribution space. Toxic comparisons will be ignored.
